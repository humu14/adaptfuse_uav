    Scene, victim and nuisance labels and RUE come from an ensemble of two AdapFuse-V1 models (grouped split, seeds 41 + 42, flip TTA, class calibration); the audio-only label from the pipeline AudioCNN; fire/smoke boxes from YOLO26s fine-tuned on CLAHE D-Fire.
